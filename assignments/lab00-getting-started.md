# Входной практикум. Среда, Maven, JUnit и GitHub

Практикум обязателен, но не оценивается как лабораторная работа. Студент выполняет его самостоятельно до первой проверки. На занятии преподаватель проверяет результат и помогает устранить только те проблемы окружения, которые студент не смог решить по справочникам.

## Цель

Проверить рабочее окружение и один раз пройти полный путь изменения программы: запуск, исправление, тест, commit, push и pull request.

## Задание

1. Клонируйте выданный приватный репозиторий.
2. Проверьте, что IDE использует Java 25.
3. В корне репозитория выполните `./mvnw test` или `.\mvnw.cmd test`.
4. Откройте готовый пример `CourseToolkit.isEven` и два проходящих теста в модуле `lab01`.
5. Запустите тесты из IDE и командной строки; исходный проект должен завершиться с `BUILD SUCCESS`.
6. Добавьте тест для нуля и убедитесь, что он проходит.
7. Создайте ветку `practice/getting-started`.
8. Сделайте содержательный commit с добавленным тестом.
9. Отправьте ветку на GitHub.
10. Создайте PR в `main` личного репозитория по шаблону курса.
11. Попросите соседа оставить один учебный комментарий в PR, если ему выдан доступ, либо разберите комментарий преподавателя.
12. После проверки преподавателем слейте PR.

## Результат

Практикум завершен, если:

- Java и Maven Wrapper запускаются;
- два исходных теста и добавленный студентом тест проходят;
- ветка видна на GitHub;
- создан и слит PR;
- студент понимает различие между локальной веткой, `origin` и PR.

Если практикум не завершен, сначала устраните проблемы окружения и только затем приступайте к лабораторной 1.

# Лабораторная работа 1. Методы, управление выполнением и тесты

## Цель работы

Освоить базовую структуру Java-программы, статические методы, условия, циклы, массивы и простые автоматические тесты.

## Что нужно знать до начала

- переменные, условия, циклы и функции в Python;
- команды `clone`, `status`, `add`, `commit`, `push`;
- действия из [входного практикума](lab00-getting-started.md).

## Языковой бюджет

Используйте примитивные типы, `String`, массивы, условия, циклы, методы и простые JUnit-тесты. Коллекции, Stream API, reflection и многопоточность пока не нужны.

## Справка

Java всегда передает аргументы по значению. Для массива копируется значение ссылки, поэтому содержимое доступного массива можно изменить. В этой работе методы не должны изменять входные массивы.

Для проверки простоты числа достаточно перебирать делители, пока `divisor * divisor <= number`. При условии `<` квадрат простого числа, например 49, будет обработан неправильно.

Пример теста приведен в [памятке JUnit](../docs/03-junit-cheatsheet.md).

## Обязательное задание

Дополните существующий класс `CourseToolkit`, не удаляя метод `isEven`:

```java
public final class CourseToolkit {
    public static boolean isEven(int number);
    public static boolean isPrime(int number);
    public static boolean isPalindrome(String text);
    public static double average(int[] values);
}
```

### Контракт

1. `isPrime` возвращает `false` для числа меньше 2.
2. `isPrime` корректно обрабатывает 2, составные числа и квадраты простых чисел.
3. `isPalindrome` сравнивает строку в точности: регистр и пробелы значимы.
4. Для `null` метод `isPalindrome` выбрасывает `IllegalArgumentException`.
5. `average` возвращает дробный результат и не изменяет массив.
6. Для `null` или пустого массива `average` выбрасывает `IllegalArgumentException`.
7. Методы ничего не печатают в консоль.

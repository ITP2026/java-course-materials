# Лабораторная работа 7. Лямбды и Stream API

## Цель работы

Научиться описывать последовательный конвейер обработки данных через `filter`, `map`, `sorted`, collectors и `Optional` без внешнего изменяемого состояния.

## Стартовые файлы

До начала работы преподаватель выдает каркас модуля `lab07`. Если каталога `lab07` нет или команда `./mvnw -pl lab07 test` сообщает, что модуль не найден, обратитесь к преподавателю и не изменяйте корневой `pom.xml` наугад.

## Что нужно знать до начала

- функциональный интерфейс и лямбда;
- method reference;
- стандартные коллекции и `Comparator`;
- базовое назначение `Optional`.

## Языковой бюджет

Используйте последовательный Stream API. `parallelStream`, reflection, собственные аннотации и многопоточность не входят в обязательную часть.

## Справка

Коллекция хранит данные, а stream описывает однократно выполняемый конвейер. `filter` и `map` являются промежуточными операциями; `toList`, `count`, `collect`, `max` — терминальными.

Не добавляйте элементы во внешний список внутри `forEach`. Результат должен формироваться терминальной операцией.

## Подготовительная часть — выполнить дома

Для изменяемого списка со значениями `"java", "", "git", "maven", "api"` получите через Stream API новый список непустых строк в верхнем регистре, отсортированный сначала по длине, затем по алфавиту. Ожидаемый результат: `"API", "GIT", "JAVA", "MAVEN"`. До обработки сохраните копию исходного списка. Добавьте тест результата и проверьте сравнением с копией, что исходный список не изменился. Включите подготовительную часть в ветку `lab/07-streams`.

## Обязательное задание

Создайте `DataAnalytics`, методы которого принимают список профильных объектов и ничего не печатают.

### Общие операции

1. Отфильтровать объекты по статусу.
2. Получить отсортированный список нормализованных текстовых категорий или меток.
3. Посчитать число объектов по категории через `groupingBy` и `counting`.
4. Найти объект с максимальным числовым показателем и вернуть `Optional`.
5. Получить новый список объектов, отсортированный по двум ключам.

### Программная инженерия

Используйте статус, категорию, название и трудоемкость задач.

### Инженерия систем искусственного интеллекта

Используйте статус, источник, метку и число признаков наблюдений.

### Ограничения

- входной список не изменяется;
- в методах аналитики нет обычных циклов;
- нет изменения внешней коллекции из лямбды;
- нет `Optional.get()` без проверки;
- порядок результата закреплен тестами;
- `parallelStream` не используется.

## Пошаговый план

1. Реализуйте простой `filter` и тест пустого результата.
2. Добавьте `map` и сортировку строк.
3. Реализуйте группировку и проверьте несколько групп.
4. Реализуйте `max` и оба случая `Optional`.
5. Составьте comparator из двух критериев.

## Обязательные тесты

- пустой список;
- один элемент;
- несколько статусов и групп;
- равные основные ключи сортировки;
- отсутствие максимального элемента;
- отсутствие изменения входного списка.

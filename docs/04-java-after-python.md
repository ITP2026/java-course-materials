# Переход с Python на Java

| Python | Java | Комментарий |
|---|---|---|
| динамический тип переменной | статический тип | тип проверяется компилятором |
| `None` | `null` | `null` допустим только для ссылочных типов |
| `def f(x)` | метод внутри класса | свободных функций на уровне файла нет |
| `list` | массив или `List<T>` | массив имеет фиксированную длину |
| `dict` | `Map<K,V>` | ключи используют `equals` и `hashCode` |
| `raise` | `throw` | создается объект исключения |
| `except` | `catch` | тип исключения указывается явно |
| `with` | try-with-resources | автоматическое закрытие ресурса |
| comprehension | цикл или Stream API | Stream API изучается позже |
| duck typing | интерфейс | контракт проверяется статически |

## Важное различие

Java передает все аргументы по значению. Для объекта передаваемым значением является копия ссылки. Метод может изменить доступный по ссылке объект, но присваивание параметру новой ссылки не меняет переменную вызывающего кода.

## Не переносите стиль Python механически

- Не храните все данные в `Map<String, Object>`, если известна структура класса.
- Не используйте `Object` вместо подходящего типа.
- Не создавайте один класс только с огромным `main`.
- Не проверяйте типы длинной цепочкой `instanceof`, если задачу решает интерфейс.

# Отладка программы

## Минимальный процесс

1. Воспроизведите ошибку одним тестом.
2. Прочитайте тип исключения и первую строку своего кода в stack trace.
3. Поставьте breakpoint перед подозрительной операцией.
4. Запустите тест в режиме Debug.
5. Проверьте значения параметров и локальных переменных.
6. Исправьте причину, а не только внешнее проявление.
7. Сохраните тест как regression test.

## Полезные действия IDE

- Step Over — выполнить текущую строку;
- Step Into — войти в вызванный метод;
- Step Out — завершить текущий метод;
- Resume — продолжить до следующего breakpoint;
- Evaluate Expression — вычислить выражение без изменения кода.

`System.out.println` допустим для короткого эксперимента, но не заменяет debugger и не должен оставаться в библиотечной логике без необходимости.
